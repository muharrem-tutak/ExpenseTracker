# Ekran görüntüleri

- `desktop.png`: masaüstü ana sayfa, aylık özet, harcama listesi ve kategori dağılımı.
- `mobile.png`: mobil görünüm.

Görüntüler yalnızca test için üretilmiş kurgusal harcamaları gösterir. Veritabanı dosyası veya veri dışa aktarımı içermez. Yeni görüntüler eklerken gerçek kişisel harcamaları, sunucu bilgilerini, kullanıcı adlarını ve tarayıcı hesap bilgilerini göstermeyin.
